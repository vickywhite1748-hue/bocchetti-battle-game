# 战斗吧！Bocchetti！

《战斗吧！Bocchetti！》是一款基于积点和角色拍立得的网页桌游灰盒版本。当前包含和平模式和竞争模式两个单机玩法。

公开游玩地址：

https://vickywhite1748-hue.github.io/bocchetti-battle-game/

## 当前版本

- 当前最新版本：`v1.5.4`。
- 支持 2-4 人单机对局。
- 支持 AI 自动参与。
- 和平模式支持角色拍立得、积点、签署拍立得、观众技能和一轮内人物羁绊。
- 竞争模式支持公开拍立得、独立积点、秘密登记、冲突掷骰、改选机会、跨小局羁绊和目标分。
- 当前仍是规则灰盒版本，后续会继续接入正式立绘和更完整的视觉表现。

## 更新记录

### v1.5.4

- 竞争模式移除“清除选择”按钮，避免误清当前拍立得选择。
- 竞争模式新增对局日志，位置与和平模式一致。
- 冲突登记新增玩家主动掷骰流程：同回合登记同一张拍立得时先进入冲突掷骰阶段，点击按钮播放动画后显示点数；同点继续重掷。
- 竞争模式第 3 回合新增一次改选机会，改选后按第 3 回合登记处理。

### v1.5.3

- 竞争模式对局页新增“重开”按钮，游戏结束后可直接回到竞争模式设置页重新开始。
- 竞争模式将“显示建议”和“辅助分析”合并为同一个按钮，开启后同时显示阶段建议和牌面分析。
- 和平模式辅助分析补充取舍说明，明确会结合公共积点、手牌、签署和羁绊给出参考。
- 和平模式辅助分析按钮移到对局页顶栏，与竞争模式保持一致。

### v1.5.2

- 修正和平模式辅助分析关闭后，页面顶部仍显示建议提示的问题。
- 公开页面重新构建并发布到 GitHub Pages，确保线上版本跟随本次更新。

### v1.5.1

- 新增单机辅助分析，和平模式手牌和竞争模式公开拍立得可显示最终成功率、期望分、风险标签和建议动作。
- 辅助分析默认关闭，仅在单机对局内手动开启；主页不显示，不会读取其他玩家秘密登记。
- 结算阶段不再允许选择未满足条件的拍立得作为计分牌，避免误结算 0 分。
- 家族荣光在 AI 和辅助估值中按 8 分参考值处理；和平模式特殊胜利和竞争模式 8 分结算规则保持不变。
- 优化辅助界面：按钮横向排列，去除重复提示，拍立得条件中的积点标记与上方积点颜色保持一致。

### v1.5.0

- 新增游戏主页，提供“和平模式”和“竞争模式”两个入口。
- 和平模式保留原有公共积点、弃置、签署、观众技能、一轮内羁绊和目标分玩法。
- 新增竞争模式单机原型：公开拍立得、独立积点、秘密登记、4 回合小局和目标分。
- 竞争模式通过“抽取积点”按钮手动切换回合；全员登记后仍保留 4 回合节奏，第 4 回合后结算。
- 竞争模式比分卡会显示每位观众已达成的拍立得，上一小局结算不会在下一小局继续占用主界面。
- 竞争模式家族荣光按 8 分高分牌结算，不直接胜利。
- 竞争模式采用跨小局羁绊，羁绊奖励统一为 +1，且与和平模式成就独立。
- 人物卡文本已同步：删除“桥上的情侣”，新增“讨厌的哥哥”，Botti《罗密欧与朱丽叶》更名为《幼小的妹妹》。

## 操作说明

1. 选择和平模式或竞争模式。
2. 按页面按钮推进抽取、登记、弃置或结算。
3. 查看页面内“游戏规则”和“辅助分析”了解当前阶段建议。
4. 如果遇到问题，可通过页面内“反馈”入口提交当前对局信息。
