# 战斗吧！Bocchetti！

《战斗吧！Bocchetti！》是一款基于积点和角色拍立得的网页桌游灰盒版本。当前包含和平模式和竞争模式两个单机玩法。

公开游玩地址：

https://vickywhite1748-hue.github.io/bocchetti-battle-game/

## 当前版本

- 当前最新版本：`v1.6.2`。
- 支持 2-4 人单机对局。
- 支持 AI 自动参与。
- 和平模式支持角色拍立得、积点、签署拍立得、观众技能和一轮内人物羁绊。
- 竞争模式支持公开拍立得、候选积点选择、公开争夺标记、秘密登记、冲突掷骰、跨小局羁绊、分层公开市场和目标分。
- 当前仍是规则灰盒版本，后续会继续接入正式立绘和更完整的视觉表现。

## 更新记录

### v1.6.2

- 重新审查全部拍立得条件和分值，收敛同分牌之间的达成难度差距。
- 部分 4 分剧情牌提高为“一个 2 + 两个 1”的条件，避免高分故事牌过于稳定。
- Botti《天生的巨星》和 Luciano《老门之后》按条件难度上调分值。
- 命运牌放宽极低频条件，减少“等量 + 禁忌 0”导致的死牌体验。
- Chichi《归来的真相》降低黑帮需求，与 Sonnyboy《继承人的代价》接近同档难度。
- 条件 UI 支持 `爱情最多1` 这类“最多 1 枚”的命运牌条件。

### v1.6.1

- 稳定牌和剧情牌只保留正向积点条件，复杂条件集中到少数命运牌。
- 命运牌的上限条件改为“不能有某类积点”，不再需要理解 `<=`。
- 普通拍立得分值收束为 1 / 2 / 3 / 4 / 5，家族荣光按 8 分处理；同难度牌重新对齐分值。
- 移除普通牌里的双禁忌极低概率条件，避免 5 分以下牌接近不可达。
- 竞争模式公开市场优先翻出稳健、剧情、命运三个层级，减少小局全是中分牌。
- 条件 UI 改回全称椭圆标签，用 `家族1`、`爱情2`、`无黑帮` 表达条件。
- 辅助分析不再展示精确数值，只保留三档模糊达成可能。
- 竞争模式目标分调整为 14 / 20 / 26。

### v1.6.0

- 竞争模式每回合保留 4 / 3 / 2 / 1 的积点节奏，但最后 1 枚改为从 2 枚候选积点中选择。
- 公开拍立得新增争夺标记；登记后每回合仍可继续争夺，减少等待感。
- 多人登记同一张拍立得时，先比较争夺标记，再比较登记回合，仍无法破平时掷骰。
- 竞争模式界面新增候选积点区、争夺标记按钮和牌面争夺数量提示。

### v1.5.5

- 竞争模式取消第 3 回合改选机会。
- 秘密登记后不可更换或撤回，结算前其他观众仍看不到你的选择。
- 移除改选按钮和相关辅助提示，减少结算前的反复操作。

### v1.5.4

- 竞争模式移除“清除选择”按钮，避免误清当前拍立得选择。

- 冲突登记新增玩家主动掷骰流程：同回合登记同一张拍立得时先进入冲突掷骰阶段，点击按钮播放动画后显示点数；同点继续重掷。
- 竞争模式第 3 回合新增一次改选机会，改选后按第 3 回合登记处理。

- 和平模式辅助分析按钮移到对局页顶栏，与竞争模式保持一致。

### v1.5.2

- 修正和平模式辅助分析关闭后，页面顶部仍显示建议提示的问题。
- 公开页面重新构建并发布到 GitHub Pages，确保线上版本跟随本次更新。

### v1.5.1

- 新增单机辅助分析，和平模式手牌和竞争模式公开拍立得可显示达成可能和建议动作。

### v1.5.0

- 新增游戏主页，提供“和平模式”和“竞争模式”两个入口。

- 竞争模式比分卡会显示每位观众已达成的拍立得，上一小局结算不会在下一小局继续占用主界面。
- 竞争模式家族荣光按 8 分高分牌结算，不直接胜利。
- 竞争模式采用跨小局羁绊，羁绊奖励统一为 +1，且与和平模式成就独立。
- 人物卡文本已同步：删除“桥上的情侣”，新增“讨厌的哥哥”，Botti《罗密欧与朱丽叶》更名为《幼小的妹妹》。

## 操作说明

1. 选择和平模式或竞争模式。
2. 按页面按钮推进抽取、登记、弃置或结算。
3. 查看页面内“游戏规则”和“辅助分析”了解当前阶段建议。
4. 如果遇到问题，可通过页面内“反馈”入口提交当前对局信息。
