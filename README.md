# 战斗吧！Bocchetti！

《战斗吧！Bocchetti！》是一款基于积点和角色拍立得的网页桌游灰盒版本。观众每轮抽取积点、弃置不合适的角色拍立得、签署拍立得，并尝试让拍立得达成条件得分。

游玩地址：

https://vickywhite1748-hue.github.io/bocchetti-battle-game/

## 当前版本

- 当前版本：`v1.2.0`。
- 支持 2-4 人单机对局。
- 支持 AI 自动参与。
- 支持角色拍立得、积点、签署拍立得、观众技能和人物羁绊。
- 当前仍是规则灰盒版本，后续会继续接入正式立绘和更完整的视觉表现。

## 操作说明

1. 选择对局人数和观众角色。
2. 每轮抽取积点。
3. 根据当前积点趋势弃置不合适的角色拍立得。
4. 第二次弃置阶段可以签署 1 张角色拍立得。
5. 最终保留 2 张角色拍立得，并选择 1 张满足条件的拍立得计分。
6. 若你的拍立得中两张形成羁绊，卡面会显示羁绊名称；结算时计分拍立得满足条件即可获得羁绊分。

## 部署

当前公开试玩版发布在 `gh-pages` 分支。发布前先构建：

```bash
set VITE_BASE_PATH=/bocchetti-battle-game/
npm run build
```

然后将 `dist/` 内容推送到 `gh-pages` 分支，并在仓库 Pages 设置中选择 `gh-pages` 分支根目录作为发布来源。
